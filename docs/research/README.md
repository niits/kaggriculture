## Quy ước

- Ghi rõ URL và ngày rà soát để theo dõi provenance.
- Phân biệt hành vi thực sự trong code với mô tả hoặc tuyên bố của tác giả.
- Tách số liệu tự báo cáo khỏi output có thể tái lập.
- Đánh giá cả tiềm năng, độ bền, chất lượng bằng chứng và khả năng tái sử dụng.
- Không coi leaderboard score hoặc benchmark trong prose là đã xác minh nếu artifact không lưu output tương ứng.
